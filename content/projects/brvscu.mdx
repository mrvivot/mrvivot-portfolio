    descEs: "Tiempo después volví al proyecto, esta vez con mi perfil de Product Designer más consolidado y con Claude y Claude Code como herramientas de trabajo. El objetivo no fue rediseñar todo desde cero — el cliente quería conservar la identidad visual — sino modernizar la base técnica y ajustar el diseño donde hiciera falta, con el mismo rigor que vengo aplicando en mi propio portfolio.\n\nAntes de tocar código, usé Claude para pensar el proyecto: evalué frameworks (descarté Next.js por sobredimensionado para un sitio institucional de cinco páginas, y Eleventy por no aportar ninguna ventaja real sobre Astro) y elegí Astro por ser static-first y tener soporte de internacionalización nativo.     descEn: "Some time later I came back to the project, this time with a more consolidated Product Designer profile and with Claude and Claude Code as working tools. The goal wasn't a full redesign — the client wanted to keep the visual identity — but to modernize the technical foundation and adjust the design where it mattered, with the same rigor I've been applying to my own portfolio.\n\nBefore touching any code, I used Claude to think through the project: I evaluated frameworks (ruling out Next.js as oversized for a five-page institutional site, and Eleventy for offering no real advantage over Astro) and chose Astro for being static-first with native internationalization support. I also defined the URL strategy — Spanish without a prefix, where SEO positioning was already earned, and English under /en/ — prioritizing that existing SEO over structural symmetry. And, at the client's explicit request, I ruled out adding a contact form."

I found and fixed several real issues: a keyboard focus bug that stayed \"stuck\" after closing a modal with the mouse, resolved with a custom pattern that distinguishes whether the user is navigating by keyboard; inverted contrast and hierarchy on modal links, fixed by moving from relying on color alone to gray text with a permanent underline; a missing single h1 per page and a disordered heading hierarchy inside the Practice Areas modals; and a missing skip-link and visible focus state on the main CTA, both added."
  - number: "06"
    titleEs: "Performance y SEO"
    titleEn: "Performance and SEO"
    descEs: "Auditar performance con Lighthouse mostró el problema dominante del sitio original: un LCP de 44 segundos en la medición inicial, producto de depender de dos CDNs externas (Bootstrap y AOS) para poder pintar la página. Tras la migración, el LCP en producción real bajó a 9.3 segundos — una mejora real y grande, aunque todavía alto para estándares actuales: el sitio sigue usando esas mismas dependencias externas, ahora dentro de un build propio con Astro, así que es trabajo pendiente que no doy por cerrado.\n\nEn SEO construí lo que no existía: sitemap y robots.txt generados automáticamente en el build, título y descripción únicos por página (antes las cinco páginas compartían el mismo título y descripción, carácter por carácter), Open Graph y Twitter Cards, datos estructurados JSON-LD (schema.org/LegalService) con la información real del estudio, y canonical + hreflang correctos para ambos idiomas.\n\nSumé también Microsoft Clarity para dejar de asumir cómo se usa el sitio y empezar a medirlo — es reciente, todavía no hay insights de comportamiento para compartir, pero es el mismo criterio que ya aplico en mi propio portfolio."
    descEn: "Auditing performance with Lighthouse revealed the original site's dominant problem: a 44-second LCP in the initial measurement, caused by depending on two external CDNs (Bootstrap and AOS) just to paint the page. After the migration, LCP on real production dropped to 9.3 seconds — a real, significant improvement, though still high by current standards: the site still relies on those same external dependencies, now wrapped inside a proper Astro build, so that's unfinished work I'm not calling done.\n\nOn SEO I built what didn't exist before: sitemap and robots.txt generated automatically at build time, unique titles and descriptions per page (previously all five pages shared the exact same title and description, character for character), Open Graph and Twitter Cards, JSON-LD structured data (schema.org/LegalService) with the firm's real information, and correct canonical + hreflang tags for both languages.\n\nI also added Microsoft Clarity to stop guessing how the site is used and start measuring it — it's recent, so there are no behavioral insights to share yet, but it's the same criterion I already apply on my own portfolio."
